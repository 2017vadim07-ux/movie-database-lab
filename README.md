# Лабораторний проект: Фільмова база

## Мета роботи
Закріпити знання про асинхронне програмування в JavaScript, Fetch API, async/await, обробку помилок, роботу з DOM та ES6+.

## Опис проекту
Односторінковий застосунок отримує список фільмів/серіалів з TV Maze API:
https://api.tvmaze.com/shows

Дані відображаються у вигляді карток.

## Основні функції
1. Завантаження даних з API через fetch та async/await.
2. Обробка помилок через try/catch.
3. Динамічне створення HTML-розмітки.
4. Пошук фільмів за назвою або жанром.
5. Сортування за алфавітом.
6. Сортування за рейтингом.

## Структура проекту
- index.html — базова HTML-сторінка.
- style.css — стилі інтерфейсу.
- script.js — логіка завантаження, фільтрації, сортування та відображення даних.
- README.md — коротка документація.

## Використані технології
- HTML
- CSS
- JavaScript
- Fetch API
- async/await
- DOM
- ES6+
